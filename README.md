# 爆走！ダンゴムシロード / DangoMushiRoad

**ONE TAKE GAME #008**  
タイトル：爆走！ダンゴムシロード  
英字名：DangoMushiRoad  
Model：GPT-5.6 Sol  
URL / リポジトリ名：`dangomushi-road`

## ゲーム概要

かわいいダンゴムシが自然の土の道を奥へ向かって走る、疑似3Dの無限ランゲームです。石や枝、空き缶などをかわし、進んだ距離（m）を伸ばしましょう。外部素材・ライブラリ・BGM・バックエンドは不要です。

## 遊び方

- **開始**：「爆走スタート！」を押すと自動で前進します。
- **左右移動**：ゲーム画面を指で押さえ、**左右に動かした距離**だけダンゴムシが動きます。押した場所へワープしません。離すとその位置で止まります。
- **PC**：マウスドラッグ、または ← → / A / D で左右移動できます。
- **まるまる**：画面下中央のボタンを**1回タップ**すると、約 **0.82秒** 丸まってすべての障害物から身を守ります。丸まり中も左右に操作できます。PCでは Space / ↓ でも使えます。
- **クールタイム**：丸まり解除後に約 **4秒**。ボタンの円形ゲージが回復すると再使用できます。防御中に衝突すると少し弾かれ、短時間減速します。
- **ゲームオーバー**：通常の姿で障害物に衝突すると終了。結果画面の「もう一度」から即再挑戦できます。
- **スコア / BEST**：走行距離（m）がスコア。BESTはブラウザの `localStorage` に保存されます。保存が禁止されているブラウザでは、そのセッション限りとなります。
- **効果音**：Web Audio APIでその場で生成します。画面の♪ボタンでミュートできます。

## GitHub Pagesへの公開

1. GitHubで `dangomushi-road` というリポジトリを作成します。
2. `index.html`、`style.css`、`game.js`、`README.md` の4ファイルを**同じ階層（ルート）**に配置します。
3. リポジトリの **Settings → Pages** で **Deploy from a branch → main → /(root)** を選び、保存します。
4. 公開例：`https://<GitHubユーザー名>.github.io/dangomushi-road/`

`index.html` をローカルブラウザで開いても遊べます。スマートフォン縦画面優先、最小320px幅・PC中央寄せに対応。

## 技術メモ

HTML / CSS / Vanilla JavaScript、Canvas 2D、Web Audio APIのみ。疑似3Dは距離に応じた投影で、道の幅・障害物の大きさ・移動速度の見え方を変化させます。障害物生成は各グループに連続した安全な回避経路を残す方式で、最初の約200mは易しめです。500m単位で難化し、最大速度に上限があります。

テスト用にURLへ `?test=1` を付けるとブラウザから開発検証用の `window.__DANGO_TEST__` APIを参照できます（通常のプレイ時には公開されません）。
